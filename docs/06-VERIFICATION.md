# 通用验收

按目标设备实际模型集合逐项测试，不预设后端或模型数量。测试是哪个版本、哪个模型、哪些参数，就只对这个组合报告结果。

|项目|执行|通过证据|
|---|---|---|
|配置保护|对比前后配置对象与本地登录文件状态|仅预期变更，无关设置与登录保留|
|原云端|经最终连接路径发真实请求|指定云端模型完成，默认和原推理选项保留|
|每个本地模型|使用客户端别名请求并确认上游|真实目标模型完成，没有静默换模型|
|协议流式|观察增量、错误与终止|增量到达且最终完成，无伪造结束|
|工具循环|让模型调用工具读取临时随机标记文件|真实工具成功，call_id/输出/最终回答一致|
|同聊天切换|云端与实际本地模型之间切换并续问|路由正确，历史与工具结果保留|
|推理与参数|对每项宣告的控制及默认行为测试|请求映射和后端实际执行一致|
|认证隔离|分别测试云端、本地和网关认证|不串用令牌，错误认证按预期拒绝|
|本地离线|在隔离环境模拟本地不可用|云端按设计可用，本地清楚失败|
|目录离线|隔离环境中关闭候选网关|目录、默认与有效能力仍可读取|
|用户界面|在目标客户端实际查看模型与控件|模型集合和推理控件与声明一致|
|生命周期|临时组件测试，再空闲窗口验正式启停|不弹意外窗口，不结束共享服务或活动请求|
|回退|执行或明确验证逆向操作|原云端可恢复，不覆盖后续无关修改|

## 推理能力的分支

- 不支持推理控制：确认没有虚假强度菜单，没有发送不支持字段；推理控制项记不适用并说明原因。
- 仅模型默认：确认默认被保留，不暗中替换成某个强度或预算。
- 有强度、开关、预算或 preset：只对支持项逐一验证，包括默认、边界和不支持输入的处理。
- 能力尚未确定：先记未验证，不作为可用选项交付。

不要以某个模型输出了较长解释来证明推理强度或预算生效。结合实际请求、服务端解析和有效参数证据；不能取得有效值时保留验证限制。

## 观察真实客户端协议

可用目标客户端实际引擎的隔离 App Server，通过初始化、thread/start、turn/start、文本增量、工具完成和 turn/completed 观测。协议以该版本为准。最终 turn.status 必须完成；HTTP 200、进程退出 0、模型自述“已调用工具”均不充分。

首次验收可缩小临时工具上下文，之后使用交付的工具集合另验。图像、语音、MCP、apps、长对话压缩、并行工具与 WebSocket 等使用时逐项追加，不外推一次文本通过。

## 生命周期测试边界

本地服务若在共享引擎上运行，不通过停止它来制造故障。先用独立 fixture 测试路由恢复和客户端退出行为。正式退出/重开安排在空闲窗口；服务重新起来不能恢复已经被杀断的响应流。

原机案例的测试结果只能作为方法参考，不计入新设备的通过项目。结果填写 [报告模板](../examples/installation-report.md)。
